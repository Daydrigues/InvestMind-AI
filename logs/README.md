Logs de Execução em Tempo Real
Este diretório é dedicado ao armazenamento de logs técnicos e de depuração (.log) gerados pelo Python e pelo framework AutoGen. Durante os debates entre os agentes e as chamadas de API, esses arquivos atuam como a "caixa-preta" do sistema. Eles são essenciais para monitorar a saúde da aplicação, permitindo o rastreamento rápido de:

Falhas de conexão HTTP e instabilidades na rede.

Erros de tokenização (excedentes de limite do LLM).

Exceções e quebras de tempo de execução (runtime errors).
